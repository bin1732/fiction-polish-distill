# Fiction Polish Distill
## 小说润色蒸馏专家

**De-AI humanization + smart polishing + style distillation + writer emulation + multilingual adaptation + self-evolving anti-AI + cross-skill synergy, all in one.**
**反AI去味 + 智能润色 + 风格蒸馏 + 作家仿写 + 多语言深度适配 + 自进化反AI + 跨Skill协同，七位一体。**

---

## ✨ Features | 特性

- 🧠 **De-AI Humanization** — Removes AI writing traces at both statistical and semantic levels, not just word substitution
  去AI去味：不是换词，是换脑——重绘认知路径，让文本双重脱离AI分布
- ✍️ **Smart Polishing** — 5 core principles + 6 soul elements, with term locking and scenario adaptation
  智能润色：5原则+6灵魂，术语锁定，六大场景适配
- 🔬 **Style Distillation** — Dual-engine extraction of writing style DNA from your texts
  风格蒸馏：双引擎从文本中提取思维框架+写作风格+表达DNA
- 📚 **Writer Emulation** — 17+ writer style profiles (Chinese/English), style migration with consistency checks
  作家仿写：17位中英文作家风格库，风格迁移+一致性校验
- 🌏 **Multilingual** — 60 languages auto-detected, deep adaptation for 4 core languages (ZH/EN/JP/KR)
  多语言：60种语言自动检测，中英日韩深度适配，轻小说/韩网文风格
- 🔄 **Self-Evolving** — Dynamic anti-AI blacklist that learns from user feedback
  自进化：动态黑名单从用户反馈中学习新AI模式
- 🤝 **Cross-Skill** — Seamless collaboration with Web Novel Writer Pro
  跨Skill协同：与网文小说签约专家联动创作

```bash
# Via CLI
skillhub install fiction-polish-distill

# Or download the ZIP and extract to your skills directory
# 或下载ZIP包解压到你的skills目录
```

### Usage | 使用

Just say what you need directly — no forced workflow:

直接说你的需求即可，不强制流程：

- "去AI味" / "de-AI this text" — Remove AI writing traces
- "润色这段" / "polish this" — Optimize expression
- "提取我的风格" / "extract my style" — Distill writing style DNA
- "用海明威风格重写" / "write like Hemingway" — Emulate a writer's style
- "轻小说风格" / "ラノベ風に" — Japanese light novel adaptation
- "进化反AI词库" / "evolve blacklist" — Trigger self-evolution
