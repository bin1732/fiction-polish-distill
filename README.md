# 小说润色蒸馏专家

小说润色蒸馏专家——反AI去味、智能润色、风格蒸馏、作家仿写、多语言深度适配、自进化反AI、模拟专家团会诊，七位一体。覆盖全球全类型小说，中英日韩四语深度适配。

## 七大核心能力

| 模块 | 功能说明 |
|------|----------|
| **反AI去味** | 多维度质量检测+针对性改写，降低AI文本痕迹，提升自然度与原创感 |
| **智能润色** | 基于内置润色规则库，按文体/场景/目标平台精准优化表达 |
| **风格蒸馏** | 从用户提供的样本文本中提炼个人写作风格，生成可复用风格档案 |
| **作家仿写** | 内置多位作家风格模型，支持指定风格定向仿写 |
| **多语言适配** | 中英日韩四语深度适配；60种语言自动检测，其余回退英文模式 |
| **自进化反AI** | 反AI黑名单持续学习进化，自适应应对检测技术更新 |
| **模拟专家团会诊** | 多角度交叉审查，模拟多位专家联合评估，输出综合诊断 |

## 覆盖范围

- **中国网文**：玄幻/都市/言情/悬疑/科幻/历史/武侠/游戏/轻小说/种田/恐怖/百合BL
- **英文小说**：Romance / Fantasy / Sci-Fi / Thriller / Horror / Mystery / YA / LitRPG / Historical / Women's Fiction
- **日本轻小说**：異世界 / 転生 / ラブコメ / ダークファンタジー
- **韩国网文**：로판 / 회귀 / 먼치킨 / 게임판타지
- **出版文学**：严肃文学/通俗小说/类型文学

## 功能特性

- **零外部依赖**：核心功能纯本地运行，规则库内置
- **自由入口**：用户决定做去AI味、润色、蒸馏还是仿写，不强制流程
- **新手引导**：首次使用触发引导，可选永久关闭
- **平台合规**：内置各小说平台AI创作规范核查工具
- **质量检测**：句长波动、连接词使用、语言检测、八项指标评分
