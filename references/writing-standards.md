# 不同题材/类型的写作标准和偏好

> 覆盖全球不同题材类型的写作规范、读者偏好、市场趋势

---

## 一、中文网文类型写作标准

### 玄幻修仙

| 维度 | 标准 |
|------|------|
| **核心卖点** | 升级体系、金手指、逆袭打脸、世界观 |
| **读者年龄** | 18-35岁男性 |
| **字数偏好** | 200-500万字（长篇） |
| **开篇公式** | 主角被欺凌/废柴→触发金手指→展现实力→引出世界观 |
| **节奏要求** | 每3章1个爽点，每10章1次小高潮，每50章1次大高潮 |
| **力量体系** | 必须有清晰的等级划分（至少5级以上） |
| **常见雷区** | 升级太慢❌ 金手指太无敌❌ 反派降智❌ |
| **平台偏好** | 起点(付费)>番茄(免费)>纵横 |

### 都市异能

| 维度 | 标准 |
|------|------|
| **核心卖点** | 身份反转、打脸、异能设定、现实代入感 |
| **字数偏好** | 100-300万字 |
| **开篇公式** | 身份对立/冲突→展现能力→反转打脸→引入更大冲突 |
| **节奏要求** | 每章有爽点，开篇3章内必须有1次反转 |
| **常见雷区** | 背景太假❌ 角色太无脑❌ 逻辑漏洞❌ |
| **平台偏好** | 番茄>起点>七猫 |

### 女频言情

| 维度 | 标准 |
|------|------|
| **核心卖点** | CP感、甜虐节奏、情感张力、代入感 |
| **读者年龄** | 16-35岁女性 |
| **字数偏好** | 50-150万字（中长篇） |
| **开篇公式** | 相遇冲突/身份反差→情感互动→关系升级→波折→HE |
| **节奏要求** | 甜虐比例7:3，每5章1次情感高潮 |
| **情感红线** | 1v1（晋江强制）、禁止NP、禁止婚内出轨美化 |
| **常见雷区** | 工业糖精❌ 人设崩塌❌ 节奏拖沓❌ |
| **平台偏好** | 晋江>番茄>七猫>长佩 |

### 悬疑推理

| 维度 | 标准 |
|------|------|
| **核心卖点** | 谜题设计、反转、逻辑严谨、氛围 |
| **读者年龄** | 20-45岁 |
| **字数偏好** | 30-100万字（中篇） |
| **开篇公式** | 案件/谜题开场→线索铺设→推理→反转→真相 |
| **节奏要求** | 每3章1个反转，每10章1个大型案件完结 |
| **常见雷区** | 线索不公平❌ 推理跳跃❌ 结局强行反转❌ |
| **平台偏好** | 起点>豆瓣>知乎盐选 |

## 二、英文小说类型写作标准

### Romance

| Dimension | Standard |
|-----------|----------|
| **Core Appeal** | Emotional connection, sexual tension, HEA |
| **Target Reader** | Women 18-55 |
| **Word Count** | 50,000-80,000 words |
| **Opening** | Meet-cute or emotional hook in first page |
| **Pacing** | Slow burn, emotional beats every 5 chapters |
| **Required Elements** | HEA/HFN guaranteed, dual POV optional |
| **Reader Tropes** | Enemies-to-lovers > Friends-to-lovers > Second chance |
| **Platform** | Amazon KDP > Wattpad |
| **Avoid** | Cheating romanticized ❌ No HEA ❌ |

### Fantasy

| Dimension | Standard |
|-----------|----------|
| **Core Appeal** | Worldbuilding, magic system, hero's journey |
| **Target Reader** | 18-45 |
| **Word Count** | 80,000-150,000 words |
| **Opening** | Inciting incident in first 3 chapters |
| **Pacing** | Quest-driven, action every 2-3 chapters |
| **Required Elements** | Consistent magic rules, character growth arc |
| **Reader Tropes** | Found family > Chosen one > Academy setting |
| **Platform** | KDP > Webnovel |
| **Avoid** | Deus ex machina ❌ Inconsistent power system ❌ |

### Thriller

| Dimension | Standard |
|-----------|----------|
| **Core Appeal** | Suspense, plot twists, pacing |
| **Target Reader** | 25-55 |
| **Word Count** | 70,000-90,000 words |
| **Opening** | Hook in first paragraph, plant first clue |
| **Pacing** | Fast, twist every 3-4 chapters |
| **Required Elements** | Red herrings, credible resolution |
| **Reader Tropes** | Unreliable narrator > Serial killer > Psychological |
| **Platform** | Amazon KDP |
| **Avoid** | Predictable ending ❌ Plot holes ❌ |

## 三、日本轻小说类型标准

| ジャンル | 読者層 | 長さ | 書き方の特徴 | 人気テンプレ |
|---------|--------|------|-------------|-------------|
| 異世界転生 | 10-30歳 | 5-20巻 | 主人公の特殊能力、スローライフ | トラックに轢かれて異世界へ |
| ラブコメ | 10-25歳 | 3-10巻 | すれ違い、勘違い、ドタバタ | 幼馴染/同級生との日常 |
| ダークファンタジー | 15-30歳 | 3-15巻 | 重い設定、哲学要素 | 復讐/裏切りからの再起 |
| なろう系 | 10-25歳 | 長期連載 | テンプレ展開、ご都合主義 | 最強無双/ハーレム |

## 四、不同类型的关键区别

| 对比维度 | 中国网文 | 英文小说 | 日本轻小说 | 韩国网文 |
|----------|---------|----------|-----------|---------|
| **连载方式** | 日更连载 | 完本/连载 | 连载→文库本 | 日更连载 |
| **每日字数** | 3000-10000 | 500-2000 | 2000-4000 | 3000-8000 |
| **典型长度** | 100-500万字 | 5-15万字 | 8-20万字 | 100-300万字 |
| **读者耐心** | 极低（3章定生死） | 中（20%处决定） | 中（1卷定生死） | 低（10章定生死） |
| **变现方式** | 付费/广告分成 | 版税/KU | 版税/文库 | 打赏/付费 |
| **AI检测力度** | 极高（朱雀/百度） | 中（Originality.ai） | 低-中 | 中 |

## 五、各类型写作模板

### 玄幻修仙开篇模板（3章）

| 章节 | 任务 | 字数 | 核心要素 |
|------|------|:----:|----------|
| 第1章 | 废柴处境→被欺凌→触发金手指 | 3000-3500 | 主角惨状+金手指初现+结尾悬念 |
| 第2章 | 金手指初用→小逆袭→新冲突 | 3000-3500 | 金手指效果+第一次打脸+更大威胁 |
| 第3章 | 正式打脸→引出世界观→新目标 | 3000-3500 | 完整打脸流程+世界背景+长期目标 |

### 英文Romance开篇模板（3章）

| Chapter | Task | Words | Key Elements |
|---------|------|:-----:|--------------|
| Ch.1 | Meet-cute → Conflict → Emotional hook | 2000-3000 | First interaction, tension, cliffhanger |
| Ch.2 | Forced proximity → Shared secret → Vulnerability | 3000-4000 | Quality time, vulnerable moment, connection |
| Ch.3 | Conflict escalation → Kiss/touch → New complication | 3000-4000 | First kiss, misunderstanding, obstacle |

### 悬疑推理开篇模板（3章）

| 章节 | 任务 | 字数 | 核心要素 |
|------|------|:----:|----------|
| 第1章 | 案件发现→主角介入→第一个线索 | 3000-4000 | 案件惊奇+主角能力+埋线 |
| 第2章 | 调查展开→嫌疑人出现→第二个线索 | 3000-4000 | 走访过程+嫌疑人+假线索 |
| 第3章 | 反转→锁定真凶→第三个线索 | 3000-4000 | 推翻判断+真凶悬念 |
