# 多语言自动检测与切换框架

> 中/英/日/韩四语自动检测 + 其他语言回退英文模式处理
> 原理：脚本（quality_check.py）可自动检测中/英/日/韩；其他语言由上层模型识别输入语言，
> 统一回退英文模式处理并输出
> 覆盖全球所有小说平台：起点、番茄、晋江、Wattpad、Amazon KDP、Webnovel、小説家になろう、カクヨム、문피아、카카오페이지 等

---

## 语言支持分层

本系统采用**分层支持架构**，确保全球任何语言的用户都能获得基础服务，同时核心语言获得深度适配：

| 层级 | 语言数量 | 支持内容 |
|------|----------|----------|
| **L1 核心深度支持** | 4种 | 完整反AI词表 + 润色规则 + 体裁适配 + 诊断检测 + 质量评分（脚本自动检测） |
| **L2 检测+回退处理** | 56种 | 上层模型识别语言 + 回退到英文模式处理（基础去AI味+润色） |
| **L3 手动指定** | 所有语言 | 用户可手动指定语言，强制切换到对应模式 |

> 诚实声明：脚本（quality_check.py）的自动检测能力为中/英/日/韩四语；
> 其余 56 种语言的"检测"由上层模型完成，处理统一回退英文模式。
> 已知边界：纯汉字日文（假名占比极低，<10%）可能被误判为中文——日文正常写作必混假名，
> 极端情况用户可手动指定语言（"日本語"）强制切换。

## 语言检测机制

| 输入情况 | 检测方式 | 处理结果 |
|----------|----------|----------|
| **中文输入** | 自动检测为中文字符 | L1核心支持：中文反AI规则+润色规则+网文适配 |
| **英文输入** | 自动检测为拉丁字符 | L1核心支持：英文反AI规则+润色规则+英文小说适配 |
| **日语输入** | 自动检测为日文字符(平假名/片假名/汉字) | L1核心支持：日文反AI规则+轻小说适配+文体切换 |
| **韩语输入** | 自动检测为韩文字符(谚文) | L1核心支持：韩文反AI规则+韩网文适配+语体切换 |
| **其他语言输入** | 上层模型识别（非脚本自动检测） | L2回退：英文模式处理（基础去AI味+润色） |
| **检测失败** | 无法识别语言 | 默认用英文处理+输出（与 quality_check.py 一致） |
| **用户手动指定** | 用户明确指定语言 | 强制切换到指定语言 |

## 语言覆盖统计

| 类别 | 数量 |
|------|------|
| **支持的语言总数** | 60种 |
| **核心语言（L1：完整反AI+润色+体裁适配，脚本自动检测）** | 4种（中文/English/日本語/한국어） |
| **检测回退语言（L2：模型识别+英文模式处理）** | 56种 |
| **覆盖的国家/地区** | 85+（手动切换表逐一列出） |
| **检测方式** | 脚本四语自动检测+模型识别+手动切换 |

> L1核心语言（中/英/日/韩）具备完整的反AI词表、润色规则、体裁适配和诊断检测。

> 用户可随时手动切换任意语言。
