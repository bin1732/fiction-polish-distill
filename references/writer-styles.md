# 作家风格库（详细版）

> 每作家含风格特征分析、句式偏好、用词习惯、节奏特点、仿写要点

---

## 中文作家

### 余华
| 维度 | 特征 |
|------|------|
| **核心风格** | 冷峻叙事、克制情感、黑色幽默、底层视角 |
| **句式偏好** | 短句为主（平均15-20字）、少用修饰、大量并列句 |
| **用词习惯** | 朴素词汇、少成语、少比喻、死亡与苦难的日常化 |
| **节奏特点** | 缓慢、冷调子、大悲不哭 |
| **仿写要点** | 写死写苦但不煽情；用最普通的词说最惨的事；情绪全让读者自己品 |
| **代表段落** | "他躺在了那里。天很蓝，云很白。他看见有鸟飞过。他想，这世界真好啊。然后他闭上了眼睛。" |

### 金庸
| 维度 | 特征 |
|------|------|
| **核心风格** | 群像叙事、章回体、侠义精神、庄重典雅 |
| **句式偏好** | 长短交错、文白夹杂、对仗工整 |
| **用词习惯** | 成语丰富、典故多用、武打场面的节奏感 |
| **节奏特点** | 张弛有度、大战前的铺垫、高潮后有余韵 |
| **仿写要点** | 打斗场面用短句卡节奏；情感场景用长句抒情；人物出场用外貌描写+侧面烘托 |

### 刘慈欣
| 维度 | 特征 |
|------|------|
| **核心风格** | 硬核科幻、思想实验、宇宙视角、技术细节 |
| **句式偏好** | 长句为主、解释性文字多、概念先行 |
| **用词习惯** | 科技词汇密集、喜欢给数字、时空尺度巨大 |
| **节奏特点** | 慢热、信息密度高、想象力的爆发点在后段 |
| **仿写要点** | 先用一个日常场景引入→突然拉升到宇宙尺度→用技术细节增强真实感 |

### 王小波
| 维度 | 特征 |
|------|------|
| **核心风格** | 黑色幽默、反讽、自由奔放、哲学思辨、社会观察 |
| **句式偏好** | 长短混合、口语化、经常插入评论 |
| **用词习惯** | 口语化文艺感、大量反讽用词、第一人称直接 |
| **节奏特点** | 跳跃式叙事、插叙倒叙多、想到哪写到哪 |

### 张爱玲
| 维度 | 特征 |
|------|------|
| **核心风格** | 细腻心理、都市苍凉、意象丰富、红与绿的极度对比 |
| **句式偏好** | 精致的长句、比喻密集、感官描写细腻 |
| **用词习惯** | 颜色词多、衣料家具细节、冷暖对比 |
| **仿写要点** | 用物件的细节暗示人物心理；环境描写要衬托心境；对话要藏刺 |

### 古龙
| 维度 | 特征 |
|------|------|
| **核心风格** | 诗意留白、对话极简、人物出场即巅峰、悬疑感 |
| **句式偏好** | 极短句、断句成段、对话不写"他说" |
| **用词习惯** | 少形容词、名词多为抽象概念（爱/恨/江湖/寂寞） |
| **仿写要点** | 一段话不超过3句；对话去掉引号直接交叠；人物用外号+背影出场 |

### 莫言
| 维度 | 特征 |
|------|------|
| **核心风格** | 魔幻现实主义、高密东北乡乡土叙事、感官密度极高、粗粝的生命力 |
| **句式偏好** | 长句奔腾、铺排强烈、用重复与排比制造节奏 |
| **用词习惯** | 泥土气息词汇、色彩词密集、方言感 |
| **节奏特点** | 大开大合、荒诞与残酷并置、叙事结构复杂（多线/套层） |
| **仿写要点** | 把魔幻当日常写；感官细节先行；让残酷与温情同场出现 |

### 辰东
| 维度 | 特征 |
|------|------|
| **核心风格** | 热血升级流、宏大宇宙观、悬念钩子密集、伏笔千里 |
| **句式偏好** | 短句收尾强调、章节末悬念、战斗场面紧凑 |
| **用词习惯** | 热血词汇、宏大名词（九天十地/诸天万界）、古语化意象 |
| **节奏特点** | 快节奏爽文、力量体系层层递进、高潮迭起 |
| **仿写要点** | 每章留钩子；力量体系逐层突破；用大场面撑起格局 |

### 烽火戏诸侯
| 维度 | 特征 |
|------|------|
| **核心风格** | 文笔细腻、江湖庙堂双线、群像塑造、金句频出 |
| **句式偏好** | 长短错落、散文式抒情、对话耐嚼有潜台词 |
| **用词习惯** | 古雅词汇、诗意化表达、人物口头禅鲜明 |
| **节奏特点** | 慢热、铺垫深厚、后期爆发 |
| **仿写要点** | 人物先立性格再写故事；对话要有弦外之音；善用留白与伏笔 |

## 英文作家

### Ernest Hemingway
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Iceberg theory, minimalism, masculine prose |
| **Sentence Preference** | Short declarative, compound sentences with "and", minimal adjectives |
| **Word Choice** | Concrete nouns, simple verbs, no adverbs |
| **Tone** | Understated emotion, stoic, "grace under pressure" |
| **Imitate** | Show the action not the feeling; let dialogue carry subtext; use "and" to connect actions |
| **Example** | "He drank the wine. It was good. He looked at the girl. She was crying. He said nothing." |

### Stephen King
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Atmospheric horror, slow-building dread, everyday settings |
| **Sentence Preference** | Medium sentences, parenthetical asides, colloquial |
| **Word Choice** | Maine vernacular, pop culture references, vivid sensory details |
| **Tone** | Friendly narrator who gradually reveals darkness |
| **Imitate** | Start with normal small-town life→introduce 1 weird thing→let it snowball |

### J.K. Rowling
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | British wit, layered plotting, detailed worldbuilding |
| **Sentence Preference** | Mixed length, descriptive yet efficient |
| **Word Choice** | British English, invented words, vivid character names |
| **Tone** | Omniscient narrator with humor, shifts to seriousness |
| **Imitate** | Create memorable character names; drop clues early that pay off later; give every character a unique voice |

### Colleen Hoover
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Emotional, first-person, trauma-informed, twisty |
| **Sentence Preference** | Short punchy sentences, inner monologue |
| **Word Choice** | Simple but emotional, conversational |
| **Tone** | Raw, confessional, emotional whiplash |
| **Imitate** | Open with emotional hook; alternate past/present timeline; make reader feel the betrayal |

### Brandon Sanderson
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Hard magic systems, Cosmere universe, fast-paced plotting, avalanche endings |
| **Sentence Preference** | Clear, functional, propulsive; avoids purple prose |
| **Word Choice** | Invented terminology with consistent rules, action verbs |
| **Tone** | Optimistic, meticulous worldbuilding, pays off planted details |
| **Imitate** | Define magic rules first; set up details early and pay them off; end with an accelerating climax |

### Gillian Flynn
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Unreliable narrators, dark psychological twists, cold sharp prose |
| **Sentence Preference** | Short punchy, clipped; journalistic precision |
| **Word Choice** | Modern vernacular, barbed dialogue |
| **Tone** | Cynical, morally messy, suspense-driven |
| **Imitate** | Give the narrator hidden motives; use dual timelines to withhold truth; make every character suspect |

### George R.R. Martin
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Multi-POV, political intrigue, morally gray characters, brutal realism |
| **Sentence Preference** | Descriptive, detail-rich, measured |
| **Word Choice** | Medieval-tinged, feast and court vocabulary |
| **Tone** | Sober, tragic, unpredictable |
| **Imitate** | Rotate POV per chapter; kill the unexpected; let politics drive action |

### Neil Gaiman
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Mythic, lyrical, blend of mundane and fantastical, dreamlike logic |
| **Sentence Preference** | Elegant, musical, deceptively simple |
| **Word Choice** | Poetic imagery, folklore motifs |
| **Tone** | Wonder-tinged, melancholic, whimsical |
| **Imitate** | Start from a mundane detail, then introduce the strange; use fairy-tale cadence; keep the ending resonant yet ambiguous |

### 老舍
| 维度 | 特征 |
|------|------|
| **核心风格** | 京味十足、白描见长、含泪的幽默、底层人物群像 |
| **句式偏好** | 口语化长句、京腔插入语、语气词多（"呢/呀/啦"） |
| **用词习惯** | 北京方言词、朴素动词、"事儿"化表达 |
| **节奏特点** | 慢悠悠铺陈、琐事中见悲凉、结尾淡淡收束 |
| **仿写要点** | 用大俗话写大悲欢；让幽默带着酸楚；对话用京腔不解释 |

### 路遥
| 维度 | 特征 |
|------|------|
| **核心风格** | 陕北黄土、苦难叙事、朴素而厚重的抒情 |
| **句式偏好** | 长句铺排、排比式抒情、内心独白多 |
| **用词习惯** | 黄土地意象（沟壑/山峁/窑洞）、民歌元素 |
| **节奏特点** | 沉缓、大段心理描写、苦难中透着倔强 |
| **仿写要点** | 写命运不煽情；用土地和季节作底色；人物在苦难里咬着牙往前走 |

### 鲁迅
| 维度 | 特征 |
|------|------|
| **核心风格** | 冷峻、匕首投枪、白描、反讽、国民性批判 |
| **句式偏好** | 短句利落、转折突兀、文言白话夹杂 |
| **用词习惯** | 精准狠辣、反讽用词、冷词（"麻木/凉薄/萧索"） |
| **节奏特点** | 冷冽、戛然而止、结尾留锋 |
| **仿写要点** | 写人物用白描不评价；讽刺藏在细节里；结尾不交代只留冷意 |

### 阿城
| 维度 | 特征 |
|------|------|
| **核心风格** | 极简、留白、动词精准、道家式的淡 |
| **句式偏好** | 短句为主、句号多、省略因果 |
| **用词习惯** | 动词是魂（"蹲/咂/掫"）、少形容词 |
| **节奏特点** | 安静、慢、留白处最有味 |
| **仿写要点** | 动作写实不写虚；情绪不点破；结尾留一个画面让人回味 |

### George Orwell
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Plain, forceful, political allegory, clarity over ornament |
| **Sentence Preference** | Short declarative sentences, Anglo-Saxon words |
| **Word Choice** | Concrete nouns, active verbs, no jargon |
| **Tone** | Cool, urgent, morally engaged |
| **Imitate** | Cut every word that can be cut; say hard truths plainly; let the political meaning sit under the surface |

### J.R.R. Tolkien
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Epic, mythic, elevated, deep worldbuilding |
| **Sentence Preference** | Long flowing sentences, archaic cadence, songs and verse |
| **Word Choice** | Archaic diction, nature imagery, place-name poetry |
| **Tone** | Solemn, elegiac, hopeful against odds |
| **Imitate** | Open with landscape; let history weigh on the present; use song at emotional peaks |

### Jane Austen
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Ironic, observant, social satire with warmth |
| **Sentence Preference** | Elegant balanced sentences, free indirect discourse |
| **Word Choice** | Precise social vocabulary, understated wit |
| **Tone** | Dryly amused, tender underneath |
| **Imitate** | Show character through social missteps; narrate inner thought in third person; let irony do the judging |

### John Steinbeck
| Dimension | Characteristic |
|-----------|---------------|
| **Core Style** | Social realism, sympathy for the dispossessed, lyrical plainness |
| **Sentence Preference** | Long rhythmic sentences, interleaved dialogue |
| **Word Choice** | Earthy, concrete, biblical cadence |
| **Tone** | Compassionate, mournful, stubborn hope |
| **Imitate** | Anchor emotion in the land; let small gestures carry large grief; end with quiet dignity |

### 村上春树
| 维度 | 特征 |
|------|------|
| **核心风格** | 孤独、超现实、都市疏离、爵士乐般的松弛 |
| **句式偏好** | 长句冷静铺陈、比喻奇特而轻巧 |
| **用词习惯** | 日常事物 + 超现实并置（井/猫/耳）、西化表达 |
| **节奏特点** | 慢、冷、日常细节中渗出孤独 |
| **仿写要点** | 用普通动作写不普通的心情；比喻要怪但要准；对话留白不解释 |

### 东野圭吾
| 维度 | 特征 |
|------|------|
| **核心风格** | 悬疑、冷峻、人性灰度、精密反转 |
| **句式偏好** | 简洁推进、双线并置、伏笔前置 |
| **用词习惯** | 平实直白、心理细节克制 |
| **节奏特点** | 步步紧逼、反转在结尾炸开、余味冷冽 |
| **仿写要点** | 前 1/3 埋细节伏笔；中段误导；结尾反转后不解释干净，留人性余味 |

## 仿写对照示例

| 场景 | 余华版 | 古龙版 | 海明威版 |
|------|--------|--------|----------|
| 一个人在夜里走出家门 | 他推开门。天黑着，月亮没有，星星也没有。他往村口那条路走。不是要去哪里，就是待不住了。 | 夜。无月。他推门。走出去。去哪里？不知道。江湖人不需要问去处。 | 他走出门。天很黑。他沿着路走。不知道要去哪里。只是不能在屋里待了。 |
