# 小说润色蒸馏专家 1.0.5

> 反AI去味 · 智能润色 · 风格蒸馏 · 作家仿写 · 多语言深度适配 · 自进化反AI · 模拟专家团会诊 · 内容安全合规

## 概述

小说润色蒸馏专家是一款面向小说创作者的专业文本处理工具，覆盖中国网文、英文小说、日本轻小说、韩国网文、出版文学等。核心支持中英日韩四语深度适配，其他语言回退到英文模式处理。**无外部依赖**：所有模块、数据、脚本、专家档案均为内置资源。

## 核心能力

| 能力 | 说明 |
|------|------|
| **反AI去味** | 清除AI写作痕迹，注入人味，14类词表+7技法+五感+温差 |
| **智能润色** | 5原则+6灵魂注入，术语锁定，场景适配，字数保底80% |
| **风格蒸馏** | 双引擎提取写作风格DNA，8维参数，交叉验证 |
| **作家仿写** | 对标17位中英文作家风格 |
| **日韩适配** | 日本轻小说/韩国网文独立风格规则+反AI |
| **自进化反AI** | 动态黑名单学习（多语言种子池），版本追踪，脚本可执行 |
| **模拟专家团会诊** | EX1-EX7 虚构专家逐项质检，与质量检测脚本标准一致 |
| **内容安全合规** | 前置内容安全过滤，涉政/涉黄/涉暴红线检测（脚本可执行） |

## 快速开始

```
"去AI味"       → 清除AI痕迹
"润色这段"     → 优化表达
"提取我的风格" → 蒸馏风格
"用XX风格写"   → 仿写作家
"轻小说"       → 日韩适配
"处理这段"     → 全流程（诊断+去AI+润色）

```

## 合规声明

本工具严格遵守国家法律法规及平台内容规范：
- 不处理涉政/涉黄/涉暴/违规内容
- 前置内容安全过滤（脚本可执行），发现违规内容直接拒绝
- 仅用于合法合规的小说创作与润色
- 不传播违规内容，不协助规避安全检测
- 模拟专家团为虚构角色，不指代任何真实个人或机构
