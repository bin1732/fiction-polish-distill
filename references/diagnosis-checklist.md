# 诊断与检查清单

> 前置CT诊断 + 后置质量检测

## 前置CT诊断

接收用户文本后，首先执行以下扫描：

```yaml
诊断报告:
  句长分布:
    平均句长: XX字
    句长方差: XX        # <0.5 → 句式偏均匀 ⚠️
    最长句: XX字
    最短句: XX字

  高频实词(Top5):
    - 词1(重复X次)
    - 词2(重复X次)      # 重复率>2% → "僵尸词" ⚠️

  逻辑词密度:
    连接词: X次          # >2次/300字 → 逻辑词过载 ❌
    禁用逻辑词: [词列表]

  情感标签词:
    数量: X次            # ≥3处 → 情感标签化 ❌
    具体: [感动/愤怒/悲伤…]

  比喻密度:
    像/仿佛/如同: X次    # >5次/章 → 比喻堆叠 ⚠️

  段落均匀度:
    最长段: XX字
    最短段: XX字
    比: X:1              # ≤3:1 → 段落均匀 ⚠️

  综合评级: 优秀/良好/需修改/需大改
```

### 异常处理

| 诊断项 | 异常信号 | 处理策略 |
|--------|----------|----------|
| 句长方差<0.5 | 句式偏均匀 | 重点打乱句式结构 |
| 连接词>2/300字 | 逻辑词过载 | 先删除显性逻辑词 |
| 情感标签词≥3 | 情感标签化 | 用身体反应替代 |
| 段落比≤3:1 | 段落均匀 | 打乱段落长度分布 |
| 比喻>5次 | 比喻堆叠 | 减少比喻，用直接描述 |
| 前100字无细节 | 概括性开头 | 重写开头从具体切入 |

## 后置质量检测

处理后逐项检查：

### 硬性指标（全部通过才交付）

| # | 检查项 | 标准 | 失败处理 |
|---|--------|------|----------|
| 1 | 句长变异系数(CV) | >0.5（短句与长句交错分布） | 调整句式分布 |
| 2 | 连续12字相同序列 | =0 | 打断重复序列 |
| 3 | 连接词密度 | ≤2次/300字 | 再删一轮连接词 |
| 4 | 前100字切入方式 | 无概括性铺垫，从具体细节/反问/惊叹切入 | 重写开头 |
| 5 | 信息保留度 | 100%（不删除原文数据/观点/事实；需原稿对照） | 补回被删信息 |
| 6 | 术语保留度 | 100%（锁定术语一个不改；需原稿对照） | 恢复被改术语 |
| 7 | 情感标签词 | <3处 | 用身体反应替代 |
| 8 | 结尾方式 | 反常识短句或反问，非鸡汤 | 重写结尾 |

> 说明：#5/#6 需原稿对照，通过 `scripts/quality_check.py --original 原稿.md [--lock 术语1,术语2]` 真实计算，未提供原稿时如实标记"未检测"，不得虚构 100%。
> 脚本可实现项：#1-#8 全部可在 `scripts/quality_check.py` 中真实执行。

### 输出格式

```yaml
质检报告:
  句长变异系数(CV): X.X          # 通过/不通过
  连接词密度: XX/300字   # 通过/不通过
  信息保留度: 100%       # 通过/不通过
  术语保留度: 100%       # 通过/不通过
  前100字切入: [具体细节/概括铺垫]
  结尾方式: [反常识短句/反问/鸡汤]
  综合判定: 通过/需修改
```
