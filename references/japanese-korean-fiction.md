# 日本轻小说与韩国网文深度适配

> 模块E参考文档：日韩小说风格规则 + 反AI检测模式

---

## 一、日本轻小说（ラノベ）

### 1.1 異世界転生（いせかいてんしょう）

**核心规则**：
- 主角OP渐进揭示——不在开篇就展现全部实力，通过事件逐步揭示
- 世界发现式构建——读者跟随主角一起发现新世界规则
- 内面独白密集——主角内心吐槽和反思占文本30-40%
- ステータス表示——能力值/技能用框格展示（模仿游戏界面）

**文体特征**：
```
俺は──目の前の光景に、思わず息を呑んだ。
（これって、マジで異世界ってやつ？）
現実を受け入れられないまま、ステータス画面が目の前に浮かぶ。
```

**反AI检测要点**：
- AI倾向：过度使用「しかし」「そして」接续，描写过于整然
- 对策：插入「─」破折号打断节奏、用「」内独白打碎叙述、倒置法
- 禁止AI模式：「まず」「次に」「最後に」→ 直接行動描写

### 1.2 ラブコメ（恋愛喜劇）

**核心规则**：
- 误解驱动——每个情节点都建立在角色间的误解之上
- 内心吐槽重——主角内心独白占比极高，多为自嘲式吐槽
- 読者に語りかけ——偶尔打破第四面墙与读者对话
- 空気読めない——主角故意读不懂气氛推动剧情

**文体特征**：
```
「えっ、それって──」
言いかけて、俺は口をつぐんだ。
（いや待て、これは罠だ。間違いなく罠だ）
「……何でもない」
```

**反AI检测要点**：
- AI倾向：情感描写直球（「彼女は嬉しかった」），对话过于通顺
- 对策：会話の途切れ（「…」「──」）、誤解の多重構造、ツッコミ独白
- 禁止AI模式：直接描写感情 → 用行動和独白间接表达

### 1.3 ダークファンタジー（暗黒幻想）

**核心规则**：
- 暗色基调——全篇笼罩在不安和危机感中
- 反英雄主角——主角非正义使者，有自己的阴暗面
- 道德的曖昧さ——没有绝对的正邪，善恶边界模糊
- 死は取り返しがつかない——角色死亡不可逆，制造紧张感

**文体特征**：
```
血の匂いが、鼻腔の奥にこびりついて離れない。
俺は──もう、戻れない。
手の中の剣が、やけに重かった。
```

**反AI检测要点**：
- AI倾向：过于理性的心理描写，道德判断过于明确
- 对策：感覚的描写（匂い/触感）優先、内面の迷いを未解決のまま放置
- 禁止AI模式：道徳的結論 → 曖昧なまま放置

### 1.4 日常系（にちじょうけい）

**核心规则**：
- 缓慢节奏——没有大起大落，小确幸累积
- 萌要素——可愛い描写是核心卖点
- 会話主体——对话占60%以上（创作特征；质检对话占比对日文仅设下限30%，对话密集不判失败，见 quality_check.py）
- ほっこり結び——每章以温暖感觉结尾

**反AI检测要点**：
- AI倾向：过于完整的叙事弧、缺少「間」
- 対策：何も起こらない場面をあえて入れる、会話の脱線

## 二、语体切换规则（日文）

### です/ます（丁寧語）vs だ/である（常体）

| 场景 | 语体 | 说明 |
|------|------|------|
| 地の文（叙述） | だ/である | 轻小说叙述基本用常体 |
| 角色对话（正式） | です/ます | 上位者/初次见面/商业 |
| 角色对话（亲密） | 口语体 | 俺/あたし+だ/だよ/じゃん |
| 内心独白 | だ/である | 基本用常体 |
| メール/手紙 | 混合 | 角色性格决定 |

### AI不自然語尾検出

| AI倾向 | 自然写法 |
|--------|----------|
| 〜である。（連続使用） | 〜だ。/〜。混用 |
| 〜しました。（過度丁寧） | 〜した。/〜んだ。 |
| 〜ということです。 | 〜ってこと。/〜って。 |
| 〜ではないでしょうか。 | 〜じゃない？/〜だろ？ |

### ギャグ挿入位置

- 緊張場面の直後 → 一行ツッコミ
- シリアス独白の途中 → 自虐的比較
- 感動場面の直後 → 読者を突き放す一言

## 三、韩国网文（웹소설）

### 3.1 로판（로맨스판타지 / Romance Fantasy）

**核心规则**：
- 貴族社会——设定以贵族/王室为核心，等级森严
- 政治陰謀——权力斗争是主线推动力
- 慢热恋爱——CP发展缓慢，误会+距离感
- 敬語体系——角色间敬语使用严格反映关系

**文体特征**
```
"공작님, 오늘의 만찬은──"
"됐다. 나가 있어."
그의 목소리에 담긴 냉기에, 하인은 고개를 숙이고 물러났다.
（이 남자, 정말……）
```

**反AI检测要点**：
- AI倾向：감정을 직접 서술（그녀는 슬펐다）、대화가 지나치게 정중
- 対策：행동으로 감정 암시、부자연스러운 침묵 삽입、독백의 파편화
- 禁止AI模式：결론적 감정 서술 → 행동/표정/침묵으로 간접 표현

### 3.2 회귀물（回帰物）

**核心规则**：
- 二度目の人生——主角回到过去重新开始
- 知識の優位性——前世记忆带来信息差优势
- 伏線回収——前世的遗憾需要逐一解决
- 選択の重み——每一次选择都有蝴蝶效应

**反AI检测要点**：
- AI倾向：回歸後의 계획이 너무 완벽、감정적 갈등 부족
- 対策：記憶의 불완전성（기억한다/기억하지 못한다）、선택의 두려움 묘사

### 3.3 먼치킨（最強キャラ物）

**核心规则**：
- 圧倒的主役——主角从开始就压倒性强
- 力幻想——爽快展開，弱者を見返す構造
- ステータス表示——能力値/スキル可視化
- 빠른 전개——遅延なし、即座に報酬

**反AI检测要点**：
- AI倾向：전투 묘사가 설명적、강함 묘사가 단조로움
- 対策：전투는 동사 연타、강함은 주변 반응으로 간접 묘사

### 3.4 게임판타지（游戏幻想）

**核心规则**：
- ゲームシステム——ステータス/レベル/スキル実世界存在
- 規則の発見——システムの法則を徐々に発見
- 最適化の楽しみ——ルールを利用する面白さ

**反AI检测要点**：
- AI倾向：システム説明が説明書的
- 対策：主人公の試行錯誤で説明、失敗も含める

## 四、语体切换规则（韩文）

### 다（平叙）/요（丁寧）/하십시오（格式）

| 场景 | 语体 | 说明 |
|------|------|------|
| 地の文（叙述） | -다 | 基本終結形 |
| 主人公独白 | -다/-지 | 内面語 |
| 対等対話 | -어/-지 | 親密関係 |
| 丁寧対話 | -요 | 一般丁寧 |
| 上位者対話 | -하십시오 | 目上/公的 |

### 漢字語（한자어）vs 固有語（고유어）

| 场景 | 偏向 | 示例 |
|------|------|------|
| 正式/学術 | 漢字語 | 고려하다（考慮） |
| 情感/日常 | 固有語 | 생각하다（想） |
| 貴族会話 | 漢字語多 | 작위/은혜/명령 |
| 庶民会話 | 固有語多 | 마음/고마워/시키다 |

### AI語尾検出

| AI倾向 | 自然写法 |
|--------|----------|
| 〜합니다。（過度丁寧） | 〜해./〜다. |
| 〜되었습니다。（古風過度） | 〜됐다./〜다. |
| 〜하는 것이다。（説明調） | 〜하는 거다./〜지. |
| 〜할 수 있습니다。（可能表現過度） | 〜할 수 있다./〜할 줄 안다. |

## 五、日韩反AI通用规则

### 5.1 共通AI检测模式

| 模式 | 中文AI | 日文AI | 韩文AI |
|------|--------|--------|--------|
| 连接词堆叠 | 首先/其次/最后 | まず/次に/最後に | 먼저/다음으로/마지막으로 |
| 过度总结 | 总而言之 | 要するに | 요컨대 |
| 情感直球 | 他很感动 | 彼は感動した | 그는 감동했다 |
| 假辩证 | 虽然…但是… | しかし…だが… | …하지만… |
| 比喻过度 | 像春天一样 | 春のように | 봄처럼 |

### 5.2 对策通用框架

1. **连接词→行動切断**：删除显性连接，用行动描写衔接
2. **情感直球→感覚代替**：用身体感受替代情感标签
3. **假辩证→独白割込**：用内心吐槽打断辩证结构
4. **比喻過度→直接描写**：去掉比喻载体，直述本体

### 5.3 语体自然化

- 日文：混用だ/である/です/ます，按场景切换，避免整然
- 韩文：混用다/요/해，按角色关系切换，避免统一
- 两种语言都需要：偶尔插入「…」「──」等中断记号

## 六、日韩 AI 特征强化（1.0.5 增强）

对应 `references/antiai_blacklist.json` 新增的日韩规则（ja-015~026 / ko-015~026，AI 句式模板 / 提示词残留 / 情感直球三类），规则词库已扩充；本文档补充使用口径。

### 6.1 日文 AI 句式模板（新增词库联动）
- 套话连接：まず/次に/最後に/要するに/まとめると → 自然接续或直接叙述
- 强调壳：重要なのは/言うまでもなく/疑いなく → 直接断言
- 时代套话：現代社会において/近年/ますます → 改为具体时间/场景锚点
- 对称结构：一方で…他方で → 拆分为自然短句

### 6.2 韩文 AI 句式模板（新增词库联动）
- 套话连接：먼저/다음으로/마지막으로/요약하면/정리하면 → 자연스러운 연결로 대체
- 强调壳：말할 필요도 없이/의심의 여지없이 → 직접 서술
- 时代套话：현대사회에서/최근/점점 → 구체적인 시간·장면으로 변경

### 6.3 AI 提示词残留（日韩铁证级）
- 日文：「以下はあなたのために」「修正した内容です」「お役に立てれば幸いです」「AIとして」等 AI 对话残留 → 删除或按人物性格改写
- 韩文：「다음은 수정된 내용입니다」「도움이 되었으면 좋겠습니다」「AI로서」等 → 삭제 또는 인물 성격에 맞게 다시 쓰기
- 发布前必须清除（与 quality_check.py residue_scan 复检：硬残留 0）

### 6.4 情感直球行为化（日韩）
- 日文：怒りを感じた/悲しみを感じた → 行動で表現（拳を握る/目を細める 等）
- 韩文：분노를 느꼈다/슬픔을 느꼈다 → 행동으로 표현（주먹을 쥐는/눈을 가늘게 뜨는 等）
- 情感通过身体反应外化，替代抽象标签
