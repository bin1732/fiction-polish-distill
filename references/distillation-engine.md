# 风格蒸馏引擎

> 双引擎 + 3轨分流 + 14种写作公式 + 交叉验证

## 3轨入口分流

系统自动根据用户输入判断走哪条轨道：

| 用户意图 | 轨道 | 产出 |
|----------|------|------|
| "提取我的写作风格" / "学我的写法" | **Track A·人物蒸馏** | 思维框架+写作风格+表达DNA |
| "蒸馏我的知识库" / "提取文档方法论" | **Track B·知识蒸馏** | 专业流程+SOP+检查清单 |
| "优化这个skill" / "重构这个skill" | **Track C·技能蒸馏** | 优化重构版/跨域复用版 |

**分流优先级**：人物意图 > 知识意图 > 技能意图

---

## Track A：人物蒸馏

### 双引擎架构

```
输入：用户提供的3-10篇文本
        │
        ├──→ 引擎A：思维蒸馏
        │    价值观体系 / 世界观与信念
        │    身份认同与立场 / 思维习惯
        │    对立面与禁忌
        │
        └──→ 引擎B：写作蒸馏
             词汇层 / 句法层 / 语气层
             篇章结构 / 修辞表达
             情感态度 / 格式适配
              │
              └──→ 双引擎交叉验证
                   思维基因 ↔ 写作物证
```

### 8维风格参数

| 维度 | 输出内容 |
|------|----------|
| **用词偏好** | 高频词TOP20+指纹词10个+口语/书面比 |
| **句式节奏** | 平均句长+句长标准差+句式分布 |
| **段落结构** | 开头类型+段落分布+结尾类型 |
| **情感色调** | 中性/积极/消极倾向 |
| **标点习惯** | 逗号密度+引号/破折号频率 |
| **论证习惯** | 数据驱动/案例驱动/类比/断言 |
| **判断力强度** | 强断/建议/中性 |
| **结构偏好** | 结论先行/总分总/时间线/问题方案 |

### 交叉验证

输出前执行交叉验证：

```
思维特征: "相信努力改变命运"
写作物证: "高频使用'坚持''成长'等词"
验证状态: "已验证"  (有写作物证支撑)
         / "推测"    (无直接物证)
         / "矛盾"    (物证与特征不一致)
```

|------|------|----------|
| **PAS** | Problem-Agitate-Solution | 痛点营销文 |
| **SCAR** | Situation-Complication-Action-Resolution | 故事型 |
| **QUEST** | Question-Emotion-Story-Truth | 教程/教育 |
| **AIDA** | Attention-Interest-Desire-Action | 营销文案 |
| **FAB** | Feature-Advantage-Benefit | 产品说明 |
| **STAR** | Situation-Task-Action-Result | 案例分享 |

## 风格注入防重复一致性约束（多模态联动）

蒸馏/仿写/拆解产出注入时，与 `scripts/deai_loop.py` 多模态替换引擎同源约束，避免"近义词替换造成新 AI 行为"：

### 1. 风格特征词不重复注入
- 同一风格特征词（口头禅/高频动词/断句习惯）在**同一段落内不重复注入**（间隔 ≥3 句）
- 蒸馏出的"作者指纹"注入时按轮换选择（与 ReplacementTracker 同机制——指纹词池 5+ 异质候选）

### 2. 多模态表达（非近义词替换）
- 同一语义（如"他很生气"）在不同位置用**不同表述维度**：行为（摔门）/环境（杯震）/对话（自语）/生理（青筋）——绝不连续用同一模态
- 近义词替换仅用于词汇级去重（TTR 提升），语义级改写必须换模态

### 3. 拆解/蒸馏产出一致性
- 拆解框架（CRISP/PEST/SWOT 等）输出的分析项之间不重复用词（每项独立表达）
- 蒸馏风格参数注入后复检：同特征词密度 ≤1 次/300 字（超出提示去重）

### 4. 仿写联动
- 作家仿写（`references/writer-styles.md` 27 位）的风格特征注入同样防重复——仿写是"风格参数 + 指纹"，不是机械近义词替换
