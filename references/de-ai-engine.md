## 乙部：硬规则清洗

### 14类AI高频词+替换词池

| 类别 | 禁用词示例 | 替换词池(随机选) |
|------|-----------|-------------------|
| 逻辑连接词 | 首先、其次、最后、综上所述、总而言之、与此同时、此外、另一方面、换句话说 | 直接句号另起、零连接词自然过渡 |
| 绝对化表述 | 完全、绝对、一定、必然、永远、总是、从不、毫无疑问 | 约八成、多数情况、通常、偶尔、有时 |

### 禁用假辩证句式
`虽然…但是…` `诚然…不过…` → `有人会说…但我亲眼见过…`
`不可否认…然而…` `即便…也…` → 直接陈述事实，去掉让步壳
`一方面…另一方面…` `既…又…` → 拆成两句自然叙述

## 甲部：人味注入

### 7个底层技法

| 技法 | 改前(AI) | 改后(人) |
|------|----------|----------|
| **直白话** | "他觉得这命令荒唐" | "他心想，这命令真够扯的" |
| **走神** | "他核对粮册发现数目不对" | "他翻着粮册，外头乌鸦叫得烦人" |
| **记错** | "他立刻明白这是陷阱" | "过了两天才回过味来" |
| **碎对话** | "你去做什么？我去查粮仓" | "你干啥去。……查个东西" |
| **长短混排** | 每句长度差不多 | 长句30-60字/短句3-8字混排 |
| **不完美** | "他推演三步锁定真凶" | "他猜了三个人前两个都错" |
| **脏细节** | 干净的场景描写 | 尿憋/呼噜/饿/脚臭 |

**使用频率**：每300-500字用1个技法，交替使用。

### 五感具象画面规则

每条独立观点必须搭配40字以内贴合主题的生活画面，含感官动词：

| 感官 | 示例 |
|------|------|
| 视觉 | 刺眼、发暗、晃了一下 |
| 听觉 | 嗡的一声、啪嗒、嘶啦 |
| 触觉 | 烫手、发凉、扎得慌 |
| 嗅味觉 | 发酸、呛鼻子、一股糊味 |

**现成场景库**：
- 居家：掀锅盖被蒸汽糊眼、关冰箱磁条啪地吸合
- 办公：弹窗消息惊得心咯噔、键盘空格磨得发亮
- 通勤：地铁刹车抓吊环晃身子、扫码手机卡顿3秒
- 消费：结账看见余额愣住、店员问塑料袋迟疑

## 丙部：深度检查

### 情绪温差强制
全文必须存在至少一处情绪降调，三选一：
1. 尖锐观点后自我拆台："当然，我自己也做不到"
2. 激昂文字中插入感官停顿："说到这里，抿了一口凉透的茶水"
3. 直白自我坦白："你问我做到了吗？没有，但我清楚方向"

### 结尾爆破标准
**禁止**：让我们一起…吧、未来可期、前路光明
**仅允许**：①反常识短句 ②直击痛点短反问

### 主语限制
**禁用**：我们、人们、大众、抽象名词做主语
**可用**：我、你、具象人物、静物主语

## 丁部：残留清除（AI 铁证级残留物）

对应 `scripts/quality_check.py` 的 residue_scan：硬残留（AI 对话/提示词痕迹）必须清除，软残留（格式/模板）建议清除。

### 1. 硬残留清除（必须）
- **提示词/对话痕迹**：删除或改写"以下是为您修改、润色和优化后的内容"、"以下是修改后的"、"好的，这是"、"希望对您有帮助"、"作为AI"、"As an AI"、"Here is the" 等整句；若属正文内容则按人物视角重写为自然表达
- **AI 拒绝语**："对不起，我不能"、"我无法完成"——如出现在正文，按人物性格改写
- 清除后复检：`quality_check.py` 残留痕迹须为硬残留 0 处（各平台已有多起因未删除此类文字被锁章的公开案例）

### 2. 软残留清除（建议）
- **Markdown 格式**：删除 **加粗 / ## 标题 / ``` 代码块 / | 表格 / --- 分隔线**，还原为纯叙事文本（正文出现 Markdown 痕迹=格式残留）
- **对称模板**：打散"一方面…另一方面""不但…而且""总而言之""综上所述""需要注意的是"——改为零连接词或自然过渡

### 3. 清除原则
- 只删残留物本身，不删正文内容（信息保留度不受影响）
- 清除后与 quality_check.py 残留扫描联动复检（硬 0 / 软尽量 0）
