# 新用户引导

> 首次使用触发一次，展示一行欢迎语（轻量版）
> 说"下次不用了"/"关闭引导" → 本会话内不再显示；说"重新开启引导" → 恢复显示
> 说明："关闭"状态随会话保存，跨新会话可能再次出现，属平台架构特性

---

## 首次引导（轻量版）

```
📖 欢迎使用「小说润色蒸馏专家 1.0.5」
支持：去AI味 · 润色 · 蒸馏 · 仿写 · 日韩适配 · 进化词库 · 专家会诊（中/英/日/韩）
▶ 直接说你想做什么即可，或说"帮助"看完整指南。说"下次不用了"关闭本提示。
```

---

## 关闭引导

```
💡 下次还需要引导吗？

→ "下次不用了" / "关闭引导"    本会话内关闭
→ "先不关"                     下次还显示
→ "重新开启引导"               恢复显示
```

---

## 快速参考卡（说"帮助"时展示）

```
📋 一句话入口：

"去AI味"       → 清除AI痕迹
"润色这段"     → 优化表达
"提取我的风格" → 蒸馏风格
"用XX风格写"   → 仿写作家
"轻小说"/"韩网文" → 日韩适配
"处理这段"     → 全流程（诊断+去AI+润色）
"专家会诊"     → 模拟专家团逐项质检

体验路线：
  A 去AI味  "帮我把这段文字去AI味"
  B 润色    "润色这段，让它更自然"
  C 蒸馏    "从我的文章里提取写作风格"
  D 仿写    "用海明威风格重写这段"
  E 全流程  "帮我处理这段文本"

语言切换：
  "English mode"  → 切换到英文
  "中文模式"      → 切换到中文
  "日本語" / "한국어" → 切换到日/韩
```
